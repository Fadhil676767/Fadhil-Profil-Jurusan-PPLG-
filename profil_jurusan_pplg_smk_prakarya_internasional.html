Apa itu Jurusan PPLG?

PPLG (Pengembangan Perangkat Lunak dan Gim) adalah program keahlian di SMK Prakarya Internasional yang berfokus pada pemahaman komprehensif terkait pembuatan perangkat lunak (software), aplikasi web, aplikasi mobile, serta pengembangan video game modern.

Siswa tidak hanya diajarkan menulis baris kode (coding), namun juga melatih pemikiran logis (*computational thinking*), perancangan UI/UX yang menarik, manajemen basis data, serta metode pengembangan aplikasi profesional seperti Agile/Scrum.

Software Development

Merancang dan membangun sistem informasi dan aplikasi web modern.

Game Development

Membuat game 2D & 3D interaktif menggunakan engine populer seperti Unity / Godot.

Kompetensi Keahlian

Materi pembelajaran terkini yang disesuaikan dengan kebutuhan industri IT.

Web Development

Menguasai HTML5, CSS3, JavaScript, Tailwind CSS, serta framework modern seperti React & Laravel untuk aplikasi full-stack.

Game Mechanics & Physics

Pembuatan logika game 2D/3D, desain karakter, sprites, animasi, sprite rigging, serta pemrograman skrip C# / C++.

Database & Cloud Management

Pemodelan database relasional (MySQL, PostgreSQL) dan NoSQL (MongoDB), RESTful API, serta manajemen server.

UI/UX Design & Prototyping

Perancangan antarmuka aplikasi yang intuitif, user journey, wireframing, dan interactive prototyping menggunakan Figma.

Prospek Karir Lulusan

Peluang kerja yang luas di berbagai sektor industri digital & startup.

01. Web & App Developer

Membangun situs web bisnis, e-commerce, dan aplikasi mobile enterprise.

02. Game Programmer

Menyusun logika permainan di game studio lokal maupun internasional.

03. UI/UX Designer

Merancang tampilan produk digital agar nyaman dan estetik bagi pengguna.
